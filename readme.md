# Kawa CMS

A modern, high-performance content management system built with cutting-edge technologies.

## Overview

Kawa CMS is a robust content management system that combines the power of Fastify and Prisma on the backend with Vue.js and Nuxt.js on the frontend, delivering a seamless and efficient content management experience.

## Tech Stack

### Backend
- **Fastify** - High-performance web framework
- **Prisma** - Next-generation ORM for Node.js and TypeScript

### Frontend
- **Vue.js** - Progressive JavaScript framework
- **Nuxt.js** - Vue.js framework for building modern web applications

## Features
- Fast and efficient content delivery
- Modern admin interface
- RESTful API
- Database-agnostic with Prisma support
- SEO-friendly
- TypeScript support
